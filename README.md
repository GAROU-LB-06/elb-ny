# ELB NY

Sitio de los indicadores ELB para TradingView: demo de la señal (entrada, stop loss y take profit 1:3), resultados del backtest, calculadora del ratio 1:3, acceso gratis y redes.

Publicado con GitHub Pages. Para actualizarlo, edita `index.html` y sube los cambios a la rama `main`.

Los resultados mostrados provienen de un backtest en el modo replay de TradingView y no garantizan resultados futuros. Nada en este sitio es consejo financiero.
